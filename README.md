# E-commerce Sales and Customer Analysis Using SQL

## Project Overview
This project focuses on analyzing e-commerce sales data using SQL. It explores customer behavior, product performance, order trends, and payment information to generate meaningful business insights.

## Objectives
- Analyze customer purchasing behavior.
- Identify top-selling products.
- Calculate total sales and revenue.
- Analyze order and payment status.
- Understand sales trends.
- Generate business insights using SQL queries.

## Tools & Technologies
- MySQL
- MySQL Workbench
- SQL

## Database Tables
1. Customers
2. Products
3. Orders
4. Order_Items
5. Payments

## SQL Concepts Used
- Database and Table Creation
- Primary Key and Foreign Key
- INSERT, SELECT, UPDATE
- WHERE, ORDER BY, LIMIT
- Aggregate Functions
- GROUP BY and HAVING
- INNER JOIN and LEFT JOIN
- Subqueries
- Common Table Expressions (CTEs)

- Explored product performance.

- Developed SQL skills for business data analysis.
